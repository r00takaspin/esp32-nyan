---

Помоги мне спарить настольное устройство Agent Buddy.

1. Вызови `buddy_status`, чтобы понять, что уже сделано.
2. Если в аргументах есть "repair" ($ARGUMENTS), сначала подтверди у меня, затем вызови
   `buddy_pair` с action `repair`. Иначе вызови `buddy_pair` с action `wizard`, чтобы
   на плате открылся мастер настройки.
3. Вызови `buddy_pair` с action `instructions` и веди меня только по недостающим шагам,
   по одному за раз, дожидаясь подтверждения каждого. После каждого шага проверяй
   результат через `buddy_status`.
