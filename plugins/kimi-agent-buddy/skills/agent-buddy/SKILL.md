# Agent Buddy (Kimi)

Плагин управляет настольной платой Agent Buddy: маленький ESP32-экран с Nyan Cat,
подключённый по USB-C (или по Bluetooth через встроенный BLE-мост). На плате должна
стоять прошивка v2 (`FW_VERSION "2.0"`) — старая прошивка не отвечает на пинг и
показывается как offline.

## Живой статус (хуки)

Плагин регистрирует хуки сессии (`SessionStart`, `UserPromptSubmit`, `PreToolUse`,
`PostToolUse`, `PostToolUseFailure`, `SubagentStop`, `Stop`, `Interrupt`, `SessionEnd`),
которые шлют состояние в демон: пользователь отправил запрос → котик «думает»,
инструмент выполняется → котик бежит с именем инструмента, ответ готов → спящий котик.
Хуки только показывают состояние и ничего не блокируют; при недоступном демоне они
завершаются молча и не мешают сессии.

## Как пользоваться

Основной путь — MCP-инструменты сервера `agent-buddy`:

- `buddy_show` — показать короткое сообщение на плате (текст до ~170 символов ASCII,
  кириллица транслитерируется; `mood`: tool / think / idle / error; `seconds`: 2–60).
  Используй для заметных вех: «сборка готова», «тесты прошли».
- `buddy_status` — статус: связь, прошивка, батарея/зарядка, Bluetooth-пэйринг,
  настройки. Если плата offline, в ответе есть причина (не подключена, порт занят,
  старая прошивка) — предложи пользователю конкретное действие.
- `buddy_settings` — изменить настройки: `brightness` 0–4, `sleep` 0/5/10/30/60 с
  (гашение экрана на спящем котике, 0 = никогда), `keys` off/auto/always (печатать ли
  y/n по Bluetooth при нажатии YES/NO на плате), `approve_timeout`, `port`.
- `buddy_pair` — Bluetooth-пэйринг: `instructions` (пошаговая инструкция),
  `wizard` (открыть мастер на плате), `repair` (перепривязка: плата забывает компьютер,
  пользователь должен также удалить старое устройство AgentBuddy в настройках
  Bluetooth компьютера).

## Как это устроено (важно для диагностики)

- MCP-сервер и CLI не держат USB-порт сами: при первом обращении автоматически
  поднимается фоновый демон `buddyd.py` (HTTP на 127.0.0.1:8789), который владеет
  портом, пингует плату каждые 2.5 с и переоткрывает её после переподключения.
- «Плата на связи» = ответила на пинг за последние 7 с. Выдернули кабель — через
  несколько секунд статус честно станет offline.
- USB-порт делится с DeepSeek Harness и прошивкой через `/tmp/nyan-buddy-bridge.lock`:
  если порт занят, демон ждёт и не мешает. Не пытайся открывать `/dev/cu.usbmodem*`
  напрямую — только через инструменты/CLI.
- Без кабеля демон сам работает через Bluetooth (хелпер `buddy-ble` собирается
  `swiftc` при первом запуске на macOS; потребуется разрешить доступ к Bluetooth).

## CLI для отладки

```
python3 <plugin_root>/scripts/buddy.py status          # статус текстом (--json для JSON)
python3 <plugin_root>/scripts/buddy.py show "текст" [mood]
python3 <plugin_root>/scripts/buddy.py set brightness 3
python3 <plugin_root>/scripts/buddy.py unpair|wizard|reboot|stop
```

Лог демона: `~/.config/agent-buddy/daemon.log`, конфиг: `~/.config/agent-buddy/config.json`.

## Ограничения

- Подтверждения прав (approve YES/NO с платы) в Kimi не пробрасываются — хук
  PermissionRequest в Kimi fire-and-forget и не может вернуть решение. Живой статус,
  показ сообщений, настройки и пэйринг работают полностью.
- Плата понимает только ASCII: русский текст уходит транслитом («Привет» → «Privet»).
